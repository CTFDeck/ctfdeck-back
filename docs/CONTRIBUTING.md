# Contributing to CTFDeck Backend

Thank you for your interest in contributing to CTFDeck! We welcome contributions from everyone.

## How to Contribute

1. **Find an Issue**: Browse our GitHub issues or create a new one to discuss your ideas.
2. **Fork and Clone**: Create a fork of the repository and clone it to your local machine.
3. **Create a Branch**: Use the [Branches Policy](BRANCHES_POLICY.md) to name your branch (e.g., `feat/CTFD-123-your-feature`).
4. **Implement Changes**: Write your code, following the coding standards mentioned in the [Developer Guide](DEVELOPMENT.md).
5. **Add Tests**: Ensure your changes are covered by unit or integration tests.
6. **Commit**: Use the [Commit Policy](COMMIT_POLICY.md) for your commit messages.
7. **Submit a PR**: Push your changes to your fork and create a Pull Request against the `main` or relevant development branch.

## Code Review Process

All pull requests will be reviewed by the maintainers. We may ask for changes or clarifications. Once approved, your PR will be merged according to the [Merge Policy](MERGE_POLICY.md).

## Community

If you have questions or want to discuss the project, please use GitHub Discussions or open an issue.

Happy hacking!
